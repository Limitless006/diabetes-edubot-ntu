# Type 2 Diabetes Educational Assistant — Group 01
## المساعد الطبي الذكي للتثقيف بمرض السكري من النوع الثاني

تطبيق ويب طبي تفاعلي متقدم مصمم لمسابقة الذكاء الاصطناعي الجامعية، مبني وفق أحدث معايير الواجهات السريرية (Clinical UI/UX) ومدعوم بنظام **Grounded Local RAG** يربط الإجابات حصراً بمصادر طبية رسمية معتمدة (**WHO, CDC, MedlinePlus, NHS, NIDDK, ADA**) لمنع الهلوسة نهائياً.

---

## 🌟 الميزات والمواصفات الرئيسية

1. **إجابات ذكية ومفتوحة بدون أسئلة ثابتة (Zero Hardcoded FAQs):**
   * يعالج أي سؤال مفاجئ يطرحه الأستاذ أو المستخدم (بالعربية الفصحى، الإنجليزية، أو اللهجة الدارجة) بمرونة فائقة مع ذاكرة محادثة متعددة الجولات (`messages[]`).
2. **شريط الأمان والخصوصية الدائم (Safety Banner):**
   * تنبيه علوي دائم يوضح أن النظام تثقيفي ولا يقدم تشخيصاً شخصياً أو خدمات طوارئ، مع حجب ورصد بيانات الهوية الشخصية (PII).
3. **كاشف الطوارئ وعلامات الخطر الحادة (Emergency Red-Flag Detector):**
   * عند ذكر أعراض الحماض الكيتوني (DKA) أو هبوط السكر الشديد أو آلام الصدر، يطلق الشات بوت إشعاراً أحمر عاجلاً بالتوجه الفوري للطوارئ أو الاتصال بالإسعاف (911 / 997 / 112).
4. **دليل قراءات سكر الدم المرجعي (Blood Glucose Reference Panel):**
   * بطاقة جانبية توضح القيم المعيارية المعتمدة من CDC لفحص التراكمي (HbA1c) والسكر الصائم، بالإضافة إلى قاعدة الـ ABCs والفحوصات الوقائية للقدمين والعينين.
5. **بطاقات البدء السريع (Quick-Start Cards):**
   * 4 محاور أساسية اختيارية تتيح للمستخدم استكشاف الموضوعات بضغطة زر واحدة.
6. **لوحة الشفافية وسجل الأسئلة وتصدير الجلسة (AI Transparency & Session Export):**
   * نافذة منبثقة توثق معمارية النظام، القواعد السريرية الخمس، والمصادر الـ 25 المعتمدة، مع زر **Session Export** لتصدير سجل أسئلة الجلسة كجدول Markdown جاهز للتسليم.
7. **توثيق المصادر المعتمدة تلقائياً (Verified Citations Footer):**
   * كل إجابة طبية تحتوي في أسفلها على بطاقات قابلة للنقر تحيل مباشرة إلى الرابط الرسمي المعتمد في `knowledge_base/verified_sources_index.json`.

## 🚀 تشغيل المشروع محلياً (Local Run Instructions)

### 1. تشغيل خادم الإنتاج المجمّع حالياً:
الخادم يعمل الآن بنجاح على المنفذ المحلي:
```
http://localhost:3000
```

### 2. لتشغيل وضع التطوير المستمر (Development Mode):
```bash
npm run dev
```

### 3. إعداد مفتاح Google Gemini API (اختياري / مدعوم تلقائياً):
النظام يعمل بكفاءة تامة حالياً عبر محرك البحث الدلالي المحلي المستند لقاعدة المعرفة `knowledge_base/` لضمان عدم الانقطاع خلال العرض المباشر (Offline / Presentation Resilience).
لتفعيل نموذج Gemini السحابي المباشر:
1. افتح ملف `.env.local` في جذر المشروع.
2. أضف مفتاحك الخاص:
   ```env
   GEMINI_API_KEY=AIzaSy...
   ```
3. أعد تشغيل التطبيق.
